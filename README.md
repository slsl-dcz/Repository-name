# 智能会商多场景协同管理系统

一个现代化的单页面应用，专为企业会议管理和协同办公设计。

## 🚀 项目特性

### 核心功能模块
- **系统概览仪表板** - 数据统计和趋势分析
- **会商会议管理** - 会议创建、编辑、查看功能
- **参会人员管理** - 人员信息管理和筛选
- **文档资料管理** - 文档上传、分类、下载
- **决策记录管理** - 决策跟踪和审批流程
- **任务分配跟踪** - 任务管理和进度监控
- **数据分析报告** - 图表可视化展示
- **系统设置配置** - 系统参数配置
- **用户权限管理** - 角色和权限控制
- **消息通知中心** - 消息推送和提醒

### 技术特性
- ✅ 响应式设计，支持多设备访问
- ✅ 现代化UI设计，用户体验优良
- ✅ 模块化架构，代码结构清晰
- ✅ 数据可视化图表支持
- ✅ 完整的CRUD操作功能
- ✅ 搜索筛选和分页功能

## 🛠️ 技术栈

- **前端框架**: 原生JavaScript (ES6+)
- **样式**: CSS3 + Flexbox + Grid
- **图表库**: Chart.js
- **图标**: Font Awesome
- **架构**: 模块化单页面应用
